## What's changed

**LEGO Mail Orders now saves only LEGO.com orders**: the ones whose order number starts with **T** (for example T514535382). Purchases with only a receipt or transaction number, such as LEGO Store receipts, are left out, and the log lists them. Orders like that saved by version 1.3.0 are removed from your `lego_mail_orders` files the next time you click **Start**.

A receipt whose PDF can be read (from Mail, or from a folder of saved receipt PDFs) still joins its T order, as before.

The LEGO.com apps for macOS and Windows are unchanged (rebuilt from the same source).

## LEGO Mail Orders (macOS)

1. Unzip it and drag **LEGO Mail Orders.app** to Applications.
2. Double-click it. The first time, macOS can't verify it because it isn't notarized: click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**. (On macOS 13–14, right-click → **Open** also works.)
3. Give it **Full Disk Access** so it can read Mail's folder: click **Open Privacy Settings** in the app, turn on **LEGO Mail Orders**, then quit and reopen the app. Or, instead, point it at a folder of emails you exported from Mail.
4. Click **Start**. When it's done, click **Open HTML report**.

Tips:
- **PDF receipts:** for Gmail, iCloud and other IMAP accounts, Mail often doesn't download attachments until you open them, and the log says how many receipts are missing. Set **Mail → Settings → Accounts → Download Attachments** to **All**, or save the receipts with **File → Save Attachments…** and choose that folder under **Receipt PDFs** in the app.
- **If an order comes out wrong,** turn on **Save matched emails for troubleshooting**. It saves what the app read next to each email's text.

Files: `~/Library/Application Support/LEGO Order Scraper/` (as `lego_mail_orders.*`, so they never overwrite the LEGO.com app's files). Log: `~/Library/Logs/LEGO Mail Orders.log`. More in [`mac-swift/README-mail.md`](https://github.com/MajorRaccoon/lego-orders-scraper/blob/main/mac-swift/README-mail.md).

## LEGO Order Scraper (macOS)

A native Swift app with LEGO.com built into its window, using Apple's WebKit. It needs no Python and downloads no browser.

1. Unzip it and drag **LEGO Order Scraper.app** to Applications (replace the old one if you have it).
2. Double-click it. On first open, follow the same **Open Anyway** step as above.
3. Click **Start** and log in to LEGO.com on the right side of the window.

To save the files somewhere else, use **Save files to → Browse…** at the top. Default folder: `~/Library/Application Support/LEGO Order Scraper/`. Log: `~/Library/Logs/LEGO Order Scraper.log`.

## Windows app (x64 and arm64)

The web UI packaged with its own Python. It uses Chromium, which downloads on the first run (about 150 MB, once).

1. Unzip it anywhere and keep the **LEGO Order Scraper** folder together.
2. Double-click **LEGO Order Scraper.exe**. If SmartScreen warns (the app isn't code-signed), click **More info → Run anyway**.
3. The page opens in your browser. Click **Start**, then log in to LEGO.com in the Chromium window that appears.
4. To quit, click **Quit app** on the page, or close the console window.

To save the files somewhere else, use **Save files to → Browse…** on the page. Default folder and log: `%LOCALAPPDATA%\LEGO Order Scraper\`.
